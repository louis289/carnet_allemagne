💡 Guide du balisage grammatical

Le carnet scout applique une coloration pédagogique pour relier les mots correspondants entre les langues. Entourez les mots correspondants avec ces balises (en utilisant le même index numérique) :

Nom / Pronom [N1]texte[/N1]

Couleur bleu. Utilisé pour les noms, pronoms et groupes nominaux.
Exemple : [N1]le chien[/N1] ➔ [N1]der Hund[/N1]

Verbe [V1]texte[/V1]

Couleur verte. Utilisé pour les verbes conjugués ou à l'infinitif.
Exemple : [V1]mange[/V1] ➔ [V1]isst[/V1]

Adjectif / Adverbe [A1]texte[/A1]

Couleur rouge. Utilisé pour les adjectifs qualificatifs et adverbes significatifs.
Exemple : [A1]très grand[/A1] ➔ [A1]sehr groß[/A1]

ℹ️ Règle d'or : L'index (ex: 1, 2, 3...) permet à l'application d'associer les blocs de mots équivalents d'une langue à l'autre. Pensez à fermer correctement vos balises (avec le slash /) pour éviter tout bug d'affichage.
